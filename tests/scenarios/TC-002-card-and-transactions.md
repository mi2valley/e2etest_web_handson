# TC-002 カードフィルタリング → 利用明細ソート・月切替

## 目的

カード一覧のブランドフィルタリング、利用明細テーブルの構造、金額ソート、月切り替えが正しく動作することを確認します。

## 事前条件

- アプリが `http://localhost:3000` で起動している
- 未ログイン状態から開始する（`launch` でセッションをリセットする）
- この手順書単体で開始し、他シナリオの実施結果を前提にしない

## 画面操作

### 1. ログイン

1. ブラウザで `http://localhost:3000` を開く
2. `test@example.com` / `password123` でログインする

### 2. カード一覧フィルタリング

1. カード一覧画面でカードが **3枚** 表示されていることを確認する
2. 「VISA」ボタンをクリックし、表示されるカードを確認する
3. 「Mastercard」ボタンをクリックし、表示されるカードを確認する
4. 「JCB」ボタンをクリックし、表示されるカードを確認する
5. 「すべて」ボタンをクリックし、カードが3枚に戻ることを確認する

### 3. 利用明細テーブルの構造確認

1. ナビゲーションの「利用明細」をクリックする
2. テーブルのヘッダー行（列名）を確認する
3. テーブルのデータ行数を確認する

### 4. 金額ソートの検証

1. 「金額」列ヘッダーのボタンをクリックする（1回目 → 昇順）
2. テーブルの **先頭行（1行目）** の金額を記録する
3. 再度「金額」列ヘッダーのボタンをクリックする（2回目 → 降順）
4. テーブルの **先頭行（1行目）** の金額を記録する

### 5. 月切り替え

1. 「2026年2月」ボタンをクリックする
2. テーブルの行数と、各行の日付列を確認する

## 期待結果

### カードフィルタリング

| フィルター | 表示されるカード名   | 枚数 |
| ---------- | -------------------- | ---- |
| なし       | 全カード             | 3    |
| VISA       | `スタンダードカード` | 1    |
| Mastercard | `ゴールドカード`     | 1    |
| JCB        | `プレミアムカード`   | 1    |
| すべて     | 全カード             | 3    |

### 利用明細テーブル

- 「利用明細」という見出しが表示されている
- テーブルのヘッダーに以下の **4列** が存在する：`日付` / `利用先` / `カテゴリ` / `金額`
- 明細データが **12件** 表示されている（2026年3月分）

### 金額ソート

- 昇順クリック後：先頭行の金額が `320 円`（最小値、利用先：`デイリーマート`）
- 降順クリック後：先頭行の金額が `32,000 円`（最大値、利用先：`テックプラザ`）

### 月切り替え

- テーブルの明細が **6件** に変わる
- 表示されている日付がすべて `2026-02-xx` である（3月の明細が混在していないこと）

## 合格/不合格判定基準

- **合格**:
  - フィルターごとに正しいカード名・枚数が表示される
  - テーブルに4列（日付/利用先/カテゴリ/金額）がある
  - 昇順で先頭行が `320 円`、降順で先頭行が `32,000 円`
  - 2月切り替えで6件に変わり、3月の明細が混在しない
- **不合格**:
  - フィルターで枚数やカード名が合わない
  - テーブルの列が欠けている
  - ソート後の先頭行の金額が期待値と異なる
  - 月切り替え後に他月のデータが混在する
