# TC-001 ログイン → カード一覧表示（正常）

## 目的

正しい認証情報でログインし、カード一覧画面へ遷移できること、およびカード3枚とナビゲーションが正しく表示されることを確認します。

## 事前条件

- アプリが `http://localhost:3000` で起動している
- 未ログイン状態である（`launch` でセッションをリセットする）
- この手順書単体で開始し、他シナリオの実施結果を前提にしない

## 画面操作

1. ブラウザで `http://localhost:3000` を開く
2. ログイン画面が表示されていることを確認する
3. 「メールアドレス」入力欄に `test@example.com` と入力する
4. 「パスワード」入力欄に `password123` と入力する
5. 「ログイン」ボタンをクリックする

## 期待結果

### ログイン後の画面遷移

- 画面が `/cards`（カード一覧）に遷移している
- 「カード一覧」という見出しテキストが表示されている

### カード一覧の表示

- カードが **3枚** 表示されている
- 以下の3つのカード名がすべて表示されている：
  - `スタンダードカード`
  - `ゴールドカード`
  - `プレミアムカード`

### ナビゲーション

- ナビゲーションバーに以下のリンクがすべて表示されている：
  - `カード一覧`
  - `利用明細`
  - `ポイント交換`
  - `プロフィール`

## 合格/不合格判定基準

- **合格**: ログイン成功、カード一覧画面へ遷移、3枚のカードが正しい名前で表示、ナビゲーションリンクが存在
- **不合格**: ログインできない、画面遷移しない、カードが3枚未満、カード名が異なる、ナビゲーションが欠けている
